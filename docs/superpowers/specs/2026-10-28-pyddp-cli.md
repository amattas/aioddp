# pyddp component spec: CLI

Date: 2026-10-28
Status: Draft
Parent: `2026-10-28-pyddp-design.md`
Module: `cli.py`, installed as `pyddp` via the `[cli]` extra (click, rich, pyyaml)

## Scope

Bench tool for a controller with no Home Assistant in the loop. It is the first thing run against new hardware and the thing used to answer the design doc's open questions about the NDB-Pro. It is a thin shell over the library: no protocol or color logic lives here, and every command resolves to a `Strip`, an optional `Segment`, and one or two library calls inside `asyncio.run`.

## Invocation

```
pyddp [GLOBAL OPTIONS] COMMAND [ARGS]
```

### Global options

| Option | Default | Notes |
|---|---|---|
| `--config PATH` | `./config.yaml` if it exists | YAML, see below. Missing file is fine unless `--config` was given explicitly |
| `--host HOST` | from config | Required somewhere for every command but `effects` and `version` |
| `--count N` | from config | Pixel count; required for every command that sends pixels, not for `query` |
| `--port N` | 4048 | |
| `--type rgb\|rgbw` | `rgb` | |
| `--order ORDER` | `RGB`, or `RGBW` with `--type rgbw` | Color order string |
| `--cap FLOAT` | 1.0 | Brightness cap. The CLI defaults to 1.0 because the bench user is standing next to the lights; hass-ddp defaults to 0.6 |
| `--gamma FLOAT` / `--no-gamma` | 2.2 | |
| `--data-type-byte INT` | unset | Override the wire byte; used to test whether a controller cares |
| `--segment NAME` | whole strip | A segment from config, or `START:LENGTH[:r]` ad hoc, e.g. `260:40:r` |
| `-v` / `-vv` | | INFO / DEBUG logging to stderr. DEBUG prints one line per packet: sequence, offset, length, push |
| `--json` | | Machine-readable output where a command prints anything |

Command-line values override config values; config values override library defaults. The merged `Strip` is built once in a click context object and validation errors print the `ConfigError` message and exit 1.

### config.yaml

```yaml
strip:
  host: 10.0.40.20
  pixel_count: 300
  port: 4048
  data_type: rgb
  color_order: GRB
  brightness_cap: 0.6
  gamma: 2.2
segments:
  roofline: { start: 0, length: 260 }
  peak: { start: 260, length: 40, reverse: true }
```

Gitignored. Unknown keys are an error so a typo does not silently fall back to a default.

## Commands

### fill

```
pyddp fill --color ff8800 [--brightness 1.0] [--segment NAME]
```

One `fill`, then exit. `--color` accepts anything `parse_color` does, plus `--kelvin N` as an alternative to `--color`.

### off

```
pyddp off [--segment NAME]
```

One `off`, exit.

### effect

```
pyddp effect NAME [--fps 30] [--param key=value ...] [--brightness 1.0] [--seed N] [--segment NAME] [--duration SECONDS] [--keep]
```

Runs an `EffectRunner` until Ctrl-C or `--duration`. On exit the segment is blanked unless `--keep`; a bench session that leaves the roof lit after Ctrl-C is a surprise, so blanking is the default here even though the library never blanks on its own. Static effects send once and exit immediately (and are not blanked, since the point was to leave them up). Params are validated before the socket opens; errors list the effect's params and defaults. Ctrl-C is handled by cancelling the runner and awaiting it, so the exit is clean and the final `off` always goes out.

A `rich` status line shows frames rendered, dropped, packets, send errors, and max render time, refreshed twice a second. Suppressed under `--json`, in which case a single JSON stats object prints on exit.

### test

```
pyddp test [--delay 0.05] [--hold 3] [--color ffffff] [--segment NAME] [--loop]
```

The hardware bring-up command. Phases, each announced on stderr:

1. **Order check**: pixel 0 red, pixel 1 green, pixel 2 blue, pixel 3 white (RGBW only, on the W channel) for `--hold` seconds (default 3). The operator confirms the colors match the labels; if not, `--order` is wrong
2. **Walk**: one pixel in `--color` walks from the first to the last pixel of the target at `--delay` seconds per step, printing the index as it goes. Where it stops is the real pixel count, and where it jumps or stalls is a wiring or output boundary
3. **Ends**: first and last pixel lit together for `--hold` seconds, then off

`--loop` repeats phase 2 until Ctrl-C. Exit blanks the target.

### query

```
pyddp --host HOST query [--timeout 1.0] [--json]
```

Asks the controller for its layout: a DDP query to the JSON config and status destinations (no HTTP; controllers that only serve the document over HTTP are read by `pyminleon`). Prints the controller identity, one row per active output (pixels, start pixel, whether the controller reverses it), the total, and a `config.yaml` snippet with one segment per output. Needs no `--count`; it is how you find one. No answer exits 2. Details in `2026-10-29-pyddp-discovery.md`.

### effects

```
pyddp effects [--json]
```

Table of effect name, static flag, description, and each param with kind, default, and range. `--json` emits the `list_effects()` structure. Needs no host.

### version

Prints `pyddp <version>` from `importlib.metadata`.

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Done |
| 1 | `ConfigError`, `EffectError`, `DDPQueryError`, usage error (click's default of 2 is remapped), bad config file |
| 2 | `DDPSendError` (could not open the socket or resolve the host); `query` with no answer |
| 130 | Ctrl-C (after clean shutdown) |

Tracebacks never print without `-vv`.

## Structure

`cli.py` is one module: a click group, a `_build_strip(ctx)` helper, a `_resolve_segment(ctx, strip, name)` helper, one function per command, and `main()`. Each command body is a small `async def _run(...)` executed with `asyncio.run`. Importing `pyddp.cli` without the extra installed raises `ImportError` with an install hint; `pyddp` itself never imports `cli`.

## Tests (`tests/test_cli.py`)

Through `click.testing.CliRunner` with the `udp_listener` fixture as the host and `--port` pointed at it. Parametrized where cases are variations of one behavior.

- `fill`, `off`: packet on the wire with expected bytes; `--segment` from config and ad hoc `START:LENGTH:r` forms
- Config precedence: config value, overridden by flag; unknown config key exits 1 with the key named
- Missing host exits 1 with a usage message; unresolvable host exits 2
- `effect chase --duration 0.2`: packets received, exit 0, final packet is zeros (blank on exit); with `--keep` the final packet is not zeros; a static effect sends one frame
- `effect` with a bad param exits 1 and the message names the param
- `test --delay 0.001` on 5 pixels: order phase packets then 5 walk packets then the ends frame then blank
- `effects --json` round-trips through `json.loads` and lists all six
- `query` with host only against the listener's responder; `--json`; no answer exits 2; unusable-layout warnings
- `version` prints the metadata version
